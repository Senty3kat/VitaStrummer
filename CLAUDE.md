# Vita Strummer — заметки для Claude

Синтезатор-страммер для PS Vita в духе Omnichord. Автор — Senty3kat (общение на русском).
Код на C (gnu99), vitasdk + vita2d. Комментарии в коде пишем по-русски.

## Как работаем

- Перед каждой итерацией смотреть свежие коммиты соседних репозиториев автора: `Senty3kat/VitaSampler`
  (основной донор: аудиопоток, канвас, приёмы UI, свои шрифты TTF в VPK), `VitaTTS`, `VitaMIDI`.
- Сборка VPK — GitHub Actions (`.github/workflows/build.yml`, контейнер `vitasdk/vitasdk`). Локально
  vitasdk нет: проверяем через хост-сборку с заглушками SDK (`host/stub`), сигнатуры как в vitasdk.
- Перед коммитом: `make -C host test` (строгая компиляция кода для Vita с `-Werror`, тесты логики,
  синт в WAV, превью экрана) и `python3 host/preview.py` (PNG с подписями). Смотреть превью глазами.
- Новые вызовы vita2d/psp2 — сначала добавить в заглушку с точной сигнатурой из vitasdk.
- Изменения выкладываем коммитом в `main` и ждём зелёную сборку в Actions.
- Автор тестирует на настоящей Vita; правки дизайна приходят со скриншотами и референсами. В отчёте всегда
  писать, что на Vita не проверялось, и давать короткий чек-лист, что проверить.
- Выкладывать в GitHub только когда автор не просит иначе (бывает: «пока не заливай» — тогда локальный коммит).

## Устройство

| Файл | Что делает |
|---|---|
| `src/main.c` | цикл: кнопки, мультитач, возврат из «сна», логика выбора аккорда |
| `src/theory.c` | тоники, типы аккордов (качество × модификатор), раскладка струн, гитарные аппликатуры |
| `src/strum.c` | геометрия клавиш и струн, детекция стрaма с долей кадра |
| `src/synth.c` | треугольный синт (отладочный) для STRUM и PAD; гитара - Карплус-Стронг + свой EQ на струну |
| `src/audio.c` | аудиопоток, блок 256 сэмплов, очередь событий без блокировок |
| `src/canvas.c` | программная отрисовка: SDF-фигуры с плитками, ленты, «пряди» струн |
| `src/ui.c` | экран: всё объёмное — текстуры при запуске; в кадре только GPU + «жидкая» подсветка |
| `src/layout.h` | вся геометрия экрана 960×544 |

## Принятые решения (не ломать без запроса автора)

**Стиль.** Общий вид — концепт «Sonara»: кремовый корпус с синей кромкой, объёмные кнопки (тень,
кромка, градиент, блик), утопленные синие панели, оранжевый — выбранное. Цвета сняты с концепта
(палитра в начале `ui.c`). Не делать минималистично.

**Колесо аккордов.** Кнопки — кольцевые сегменты: сильно скруглённые трапеции с осевой симметрией,
плотно, ровный зазор `SEG_GAP`. Аккорд в три шага: внешнее кольцо — тоника (квинтовый круг, касание
«залипает», повторное — сброс), центр — maj (верх) / min (низ), внутреннее кольцо — модификатор
(9 кнопок: triad, 7, maj7, 6, 9, add9, sus2, sus4, aug/dim; подписи меняются под качество).
Нажимается вся долька круга, не только кнопка. Круг — сброс аккорда.

**Струнная панель** — точно по первому концепту автора (`strummer_ui_concept_v10`, он ровно под экран
Vita в масштабе 2×): 25 фортепианных клавиш C4–C6, чёрные выступают влево, у белых вырезы под чёрные;
каждая клавиша сужается в нить, нить S-образно уходит к своей полосе и плавно расширяется в неё;
полосы одинаковые, почти вплотную. **Всё одного цвета.** Подписей нот нет.

**Аккорд на струнах.** Без аккорда — хроматика. С аккордом струны идут парами (`CHORD_SPREAD` = 2),
каждая пара — следующий звук аккорда вверх: не больше двух одинаковых нот подряд, 13 звуков,
у трезвучий больше 4 октав. Число клавиш не увеличивать — автору нужен диапазон именно в аккорде.

**«Жидкая» подсветка.** Светятся только задетые струны (тап — одна, проведение — все пройденные,
одинаково, без «зебры»). Цвет растекается вдоль струны от точки касания по всей её длине
(клавиша — нить — полоса), удары сливаются в одну жидкость (сумма гауссовых капель, мягкое
насыщение), палец на струне ведёт каплю за собой. Рисуется в полном разрешении по пикселям
своей струны — без ступенек. Не кольца и не «круги на воде». Цвета — с постеров Retoka (референсы
автора): голубая кромка, бледно-жёлтый, янтарь, оранжевый, красный, вишнёвый, синее ядро.
От первой pinterest-картинки (размытые пятна) брать только цвета, не формы.

**Производительность.** Ничего объёмного не рисовать процессором в кадре: только при запуске
(`build_all`) в текстуры. Текстуры, которые процессор пишет каждый кадр, — по кругу из трёх.
При «сне» консоли — пересоздать текстуры и аудиопорт.

**Режим «Гитара»** (третий режим). Колесо то же; справа гриф: 6 струн, **толстая внизу** (как видит
зритель — автор так попросил), головка слева, лады 1–12 с настоящими пропорциями, точки 3/5/7/9/12, порожек,
часть розетки. Под грифом полоска позиций + AUTO (`st.gpos` — лад, `guitar_voicing(..., pos)`, `g.pos` — взятая).
**Мажор и минор** (автор: «всего 3-4 самых распространённых с басом на 5-6 струнах»): только привычные формы
(`MAJ_SHAPES`/`MIN_SHAPES` в `theory.c`) — открытая (C, A, G, E, D, Am, Em, Dm; D/Dm с басом на 4-й — исключение),
баррэ «ми» от 6-й, баррэ «ля» от 5-й, у мажора ещё форма «до» от 5-й; в пределах 12 ладов. На полоске номера
только у них, касание пустой ячейки — ближайшая. Bb — `x 1 3 3 3 1`, не `x 1 0 3 3 1`.
**Остальные аккорды** — позиции 1–9 (`GT_POS_CX`), у каждой своя форма: со 2-й нижний зажатый лад ровно =
позиции, иначе форма, которой нет у других позиций (можно глушить любые струны, со штрафом). Аппликатуры — перебором
позиций (`guitar_voicing`), должны совпадать с учебными (тест в `host/tests.c`). На ладах — оранжевые
точки, баррэ — полоской, «x»/«o» у порожка, аппликатура на табло. **Удар по струне гитары** — при каждом пересечении её линии (`strum_gtr_move`, полоса `GTR_LINE_HYST`
у линии), вниз и вверх: тремоло коротким движением через одну струну (автор: «очень большое расстояние,
чтобы задеть одну струну дважды»). Касание — струна под пальцем; первое пересечение этой же струны
сразу после касания — тот же удар. Звук: на струне один голос (две поляризации,
мягкий фильтр в петле, щипок — форма оттянутой струны + шум), свой EQ/тембр на струну, общий корпус
(3 резонанса) и маленькая комната. Сустейн длинный (`GTR_RING` 1.45, открытые ещё ×1.3 и с меньшими потерями
в петле — «глубина», автор просил), в режиме сустейна ×2.6. Лад влияет на тембр (`synth_guitar(..., fret, ...)`): выше по грифу — меньше верхов,
круглее, короче (автор: «на реальной гитаре позиция меняет звук очень существенно»). Автору прошлый звук казался «FM-ным» — не возвращать голый шум и
пресенс-пики. Strum и Pad автору нравятся — их звук не трогать без запроса. смена аккорда глушит только струны с изменившейся нотой, сила — от скорости.

**Быстрые аккорды.** 8 слотов: D-pad (вверх, вправо, вниз, влево) и левый стик так же. Просто нажатие —
вызвать, с SELECT — сохранить (без аккорда — очистить). Короткий SELECT без комбинации — смена режима.
Показаны двумя крестовинами в углах слева от колеса. **Громкость** — капсула справа сверху, ручка только
в Pad (громкость пэда = баланс пэда и струн); громкость струн не регулируется (70). **Защита от случайных
касаний**: кнопки верхней полосы (режим, октава, транспозиция, табло, громкость) не срабатывают, пока палец
на струнах и ещё `PLAY_GUARD_S` (0.7 с) после — автор задевал их во время игры. Режим, октава, транспозиция, громкости, слоты — в `ux0:data/Strummer/settings.bin`.

**Тональность.** Вкл/выкл — Треугольник или касание табло (курки L/R не трогать — это октава).
Берётся от текущего аккорда. Ступени на колесе, чужие ноты приглушены, касание ноты лада ставит
качество по ступени (vii° — dim). Без аккорда струны Strum/Pad — по ладу (`stringmap_build_scale`).
**Задняя панель** — под правой рукой palm mute в Strum/Guitar (`BACK_PALM_X0/X1`), под левой — сустейн
(`BACK_SUS_X0/X1`, `synth_sustain`: страммер ×2.6, отпускание пэда ×5, гитара ×2.6, смена аккорда не глушит
гитару). Самые края не считаются — там пальцы держат консоль.

**Хитбоксы клавиш** (`strum.c`, полосы `g_band_k/a/b`), как сформулировал автор: левее `KZ_BLACK` (где
выступают чёрные) — только чёрные, и в щелях между ними; на середине и передней части белых (правее
`KZ_WHITE`) — только белые, даже там, где ещё нарисован хвост чёрной; между ними узкий переход по рисунку.
Первая версия (по рисунку на всей ширине чёрных) автору показалась «без изменений». На нитях — плавный переход к струнам, его не трогать (автору нравится). Звук и подсветка
используют одни и те же функции (`strum_*_xy`, `strum_cross`).

**Транспозиция** (`st.transpose`, −6..+6, пилюля TRANS рядом с OCTAVE) — только звук: колесо и табло
показывают выбранный аккорд; у гитары как каподастр. **Подсветка клавиш аккорда** в Strum/Pad — по нотам
выбранного аккорда (тоника ярче), еле заметно; текстура пишется только при смене аккорда, две по очереди.
**Быстрые аккорды** хранят и октаву, и позицию на грифе (`quick_code(..., oct, gpos)`; старые коды —
октава 0, позиция авто).

**Производительность «жидкости».** Автор видел просадки до 27 fps. Теперь: таблицы вместо expf,
клетка/доля пикселя заранее (в кадре нет деления — у Cortex-A9 нет аппаратного деления), запись
сразу в текстуру и только пикселей горящих струн. Не возвращать полное копирование панели в кадре.
Если снова тормозит — следующий шаг: считать подсветку в отдельном потоке на свободном ядре или
обновлять её 30 раз в секунду.

## Открытые вопросы и планы

- Настоящий звук вместо треугольника (позже), звук без щелчков (см. гранулы в VitaSampler v1.4).
- Свой жирный шрифт TTF в VPK (как в VitaSampler v1.3) вместо системного PGF.
- Задняя панель как модификатор аккорда — отложено. MIDI (VitaMIDI) — рано.
- Название приложения рабочее («STRUMMER»).
