# Vita Strummer — заметки для Claude

Синтезатор-страммер для PS Vita в духе Omnichord. Автор — Senty3kat (общение на русском).
Код на C (gnu99), vitasdk + vita2d. Комментарии в коде пишем по-русски.

## Как работаем

- Перед каждой итерацией смотреть свежие коммиты соседних репозиториев автора: `Senty3kat/VitaSampler`
  (основной донор: аудиопоток, канвас, приёмы UI, свои шрифты TTF в VPK), `VitaTTS`, `VitaMIDI`.
- Сборка VPK — GitHub Actions (`.github/workflows/build.yml`, контейнер `vitasdk/vitasdk`). Локально
  vitasdk нет: проверяем через хост-сборку с заглушками SDK (`host/stub`), сигнатуры как в vitasdk.
- Перед коммитом: `make -C host test` (строгая компиляция кода для Vita с `-Werror`, тесты логики,
  синт в WAV, превью экрана) и `python3 host/preview.py` (PNG с подписями). Смотреть превью глазами.
- Новые вызовы vita2d/psp2 — сначала добавить в заглушку с точной сигнатурой из vitasdk.
- Изменения выкладываем коммитом в `main` и ждём зелёную сборку в Actions.
- Автор тестирует на настоящей Vita; правки дизайна приходят со скриншотами и референсами.

## Устройство

| Файл | Что делает |
|---|---|
| `src/main.c` | цикл: кнопки, мультитач, возврат из «сна», логика выбора аккорда |
| `src/theory.c` | тоники, типы аккордов (качество × модификатор), раскладка струн по зонам |
| `src/strum.c` | геометрия клавиш и струн, детекция стрaма с долей кадра |
| `src/synth.c` | треугольный синт (пока для отладки): голоса STRUM и PAD |
| `src/audio.c` | аудиопоток, блок 256 сэмплов, очередь событий без блокировок |
| `src/canvas.c` | программная отрисовка: SDF-фигуры с плитками, ленты, «пряди» струн |
| `src/ui.c` | экран: всё объёмное — текстуры при запуске; в кадре только GPU + «жидкая» подсветка |
| `src/layout.h` | вся геометрия экрана 960×544 |

## Принятые решения (не ломать без запроса автора)

**Стиль.** Общий вид — концепт «Sonara»: кремовый корпус с синей кромкой, объёмные кнопки (тень,
кромка, градиент, блик), утопленные синие панели, оранжевый — выбранное. Цвета сняты с концепта
(палитра в начале `ui.c`). Не делать минималистично.

**Колесо аккордов.** Кнопки — кольцевые сегменты: сильно скруглённые трапеции с осевой симметрией,
плотно, ровный зазор `SEG_GAP`. Аккорд в три шага: внешнее кольцо — тоника (квинтовый круг, касание
«залипает», повторное — сброс), центр — maj (верх) / min (низ), внутреннее кольцо — модификатор
(9 кнопок: triad, 7, maj7, 6, 9, add9, sus2, sus4, aug/dim; подписи меняются под качество).
Нажимается вся долька круга, не только кнопка. Круг — сброс аккорда.

**Струнная панель** — точно по первому концепту автора (`strummer_ui_concept_v10`, он ровно под экран
Vita в масштабе 2×): 25 фортепианных клавиш C4–C6, чёрные выступают влево, у белых вырезы под чёрные;
каждая клавиша сужается в нить, нить S-образно уходит к своей полосе и плавно расширяется в неё;
полосы одинаковые, почти вплотную. **Всё одного цвета.** Подписей нот нет.

**Аккорд на струнах.** Без аккорда — хроматика. С аккордом струны идут парами (`CHORD_SPREAD` = 2),
каждая пара — следующий звук аккорда вверх: не больше двух одинаковых нот подряд, 13 звуков,
у трезвучий больше 4 октав. Число клавиш не увеличивать — автору нужен диапазон именно в аккорде.

**«Жидкая» подсветка.** Светятся только задетые струны (тап — одна, проведение — все пройденные,
одинаково, без «зебры»). Цвет растекается вдоль струны от точки касания по всей её длине
(клавиша — нить — полоса), удары сливаются в одну жидкость (сумма гауссовых капель, мягкое
насыщение), палец на струне ведёт каплю за собой. Рисуется в полном разрешении по пикселям
своей струны — без ступенек. Не кольца и не «круги на воде». Цвета — с постеров Retoka (референсы
автора): голубая кромка, бледно-жёлтый, янтарь, оранжевый, красный, вишнёвый, синее ядро.
От первой pinterest-картинки (размытые пятна) брать только цвета, не формы.

**Производительность.** Ничего объёмного не рисовать процессором в кадре: только при запуске
(`build_all`) в текстуры. Текстуры, которые процессор пишет каждый кадр, — по кругу из трёх.
При «сне» консоли — пересоздать текстуры и аудиопорт.

## Открытые вопросы и планы

- Настоящий звук вместо треугольника (позже), звук без щелчков (см. гранулы в VitaSampler v1.4).
- Свой жирный шрифт TTF в VPK (как в VitaSampler v1.3) вместо системного PGF.
- Задняя панель как модификатор аккорда — отложено. MIDI (VitaMIDI) — рано.
- Название приложения рабочее («STRUMMER»).
