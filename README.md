# Vita Strummer

Синтезатор-страммер для PS Vita в духе Omnichord. Версия 0.5: играбельный прототип с треугольной волной для отладки и интерфейсом по концептам.

## Управление

**Колесо слева** — аккорд выбирается в три шага:
1. Внешнее кольцо — тоника (квинтовый круг). Касание — аккорд «залипает», повторное касание той же тоники — сброс.
2. Центр — качество: верхняя половина maj, нижняя min.
3. Внутреннее кольцо — модификатор: triad, 7, maj7, 6, 9, add9, sus2, sus4, aug. Подписи меняются под качество: у минора m7, mM7, m6, m9, madd9, dim.
- Кнопка **Круг** — сброс аккорда. Срабатывает вся долька круга, не только сама кнопка.

**Струнная панель справа** — 25 клавиш, каждая переходит в свою струну.
- Без аккорда — хроматика C4…C6.
- С аккордом струны идут парами: каждая пара — следующий звук аккорда вверх (не больше двух одинаковых подряд). 13 звуков: у трезвучия это больше четырёх октав, как у Omnichord. Пара при проведении звучит один раз. Струны с тоникой слегка подсвечены.
- Касание и проведение дают «жидкую» подсветку: светятся только задетые струны (все пройденные — одинаково), по каждой от точки касания растекается цвет — по полосе, нити и клавише; удары сливаются в одну жидкость, палец на струне ведёт каплю за собой. Цвет по густоте, как слои на постерах Retoka: синее ядро, вишнёвый, красный, оранжевый, янтарь, бледно-жёлтый, голубая кромка.
- Играть можно и по клавишам, и по струнам; касание — одна струна, проведение — все пересечённые. Несколько пальцев одновременно.

**Сверху**
- **MODE** (или **SELECT**): Strum — звучат струны; Pad — аккорд звучит, пока выбран, струны тоже играют.
- **OCTAVE** (или **L / R**): сдвиг струн и пэда, −2…+2.
- Табло показывает текущий аккорд.
- **START** — показать/скрыть отладку: кадры в секунду, голоса, `xrun` (сколько раз аудиоблок опоздал; если растёт при игре — слышны щелчки).

Лог: `ux0:data/Strummer/log.txt` (там же время построения графики при запуске).

## Устройство

| Файл | Что делает |
|---|---|
| `src/main.c` | цикл: кнопки, мультитач, возврат из «сна» |
| `src/theory.c` | тоники, модификаторы, раскладка струн по зонам |
| `src/strum.c` | геометрия клавиш и струн, детекция стрaма с долей кадра |
| `src/synth.c` | треугольный синт: голоса STRUM (щипок) и PAD (держится) |
| `src/audio.c` | аудиопоток, блок 256 сэмплов (5.3 мс), очередь событий без блокировок |
| `src/canvas.c` | программная отрисовка со сглаживанием: фигуры через расстояние до контура, ленты, звёзды |
| `src/ui.c` | экран: всё объёмное строится при запуске в текстуры, в кадре GPU только накладывает их |

Графика: при запуске процессор один раз рисует фон, два варианта струнной панели (оранжевый и приглушённый) и спрайты всех кнопок во всех состояниях. Подсветка клавиш и вспышки струн — это куски готовых текстур, поэтому смена аккорда не нагружает процессор во время игры.

## Сборка

GitHub Actions собирает VPK (артефакт `Strummer-vpk`) так же, как в VitaSampler.

Без vitasdk можно проверить логику на обычном Linux:

```
make -C host test          # тесты, синт в host/out/synth_demo.wav, превью экрана host/out/*.ppm
python3 host/preview.py    # превью в PNG с подписями (нужен Pillow; шрифт приблизительный)
```
